# 军师 1.4 开发与扩展

主程序保留 1.3 Python 引擎和 JS 面板。模块职责：capture/ocr/uia_reader 只读采集；evidence 维护观察证据与显式更正；vision 和 avmedia 负责图片、文件语音与视频采样；engine 编排；modelrouter 控制职责、调用次数、时间和估算费用；harness_adapter 接官方 SDK；replycheck 复核候选；inputguard/fill 独立执行微信输入保护。

本地 API 继续兼容 1.0，证据扩展版本 1.1。仅监听 127.0.0.1，Windows 使用排他端口绑定。接口要求同用户 DPAPI 实例令牌、正确 Host 和同源 Origin。不向外部网页开放 CORS。SDK/client.py 读取 instance.dpapi；不要将令牌放进文档、日志或插件上下文。

接口：GET /state、/participants、/capabilities、/models、/extensions、/uia；POST /analyze-text、/regenerate、/settings、/models、/evidence、/correct-message、/memory-confirm、/media-file、/media-job、/verify-extension。/fill 只填入、不发送，独立保护不可由模型指令绕过。媒体上传上限 20MB，其他请求上限 256KB。

证据更正请求示例：`{"session":"当前会话","message_id":"读回提供的编号","patch":{"text":"核对后的文字","kind":"text"}}`。关联人物使用当前会话的 speaker_id。跨会话人物编号会被拒绝。模型目录请求示例：`{"models":[{"id":"local-review","base":"http://127.0.0.1:11434/v1","model":"模型名","roles":["review"],"enabled":true,"max_request_cost":0}],"keys":{}}`。密钥单独保存在 model-ID.dpapi，不回显。

MCP：运行安装目录 runtime/python.exe，参数 `-X utf8 sdk/mcp_bridge.py`。工具提供读上下文、人物线索、分析用户指定文字、扩展清单和能力查询，不提供发送消息或修改应用管理配置。连接外部 AI 后，调用者能够读取聊天上下文；只向用户信任的客户端开放。

扩展清单示例：`{"api_version":"1.0","entry":"extension.py","name":"我的扩展","permissions":["read_context"]}`。在 `%LOCALAPPDATA%/Junshi/extensions/插件编号/` 放置清单和代码，代码实现 `annotate_messages(messages,context)`，返回 `{"note":"补充说明"}`。仅提供消息和最小上下文，不继承应用令牌或 API 密钥环境变量。执行最长三秒，错误留作警告，基础分析继续。

示例扩展在 sdk/example-extension。先运行 `runtime/python.exe -X utf8 engine/extensions.py --verify 扩展根目录 插件编号`，或在设置中验证，然后开启。验证只允许有限依赖，拒绝明显的文件、动态执行与反射行为；不能替代代码审阅和操作系统沙箱。恶意代码仍可能绕过静态检查，因而此版本只支持可信扩展，不应宣传可安全运行任意 AI 代码。

新增模型通过 OpenAI 兼容接口接入，视觉另保留 Ollama 原生 /api/chat 支持。仅视觉使用 GPU，CPU int8 Whisper 转写；本地视觉串行，避免 4GB 显存多个请求并发。Harness 请求也串行，避免取消一个任务时终止另一个任务的共享进程。复核不使用多数投票，基于可见证据和用户确认信息进行检查，仍需人工最终确认。

固定依赖：deepseek-harness-sdk==0.1.5rc1；uiautomation==2.0.29；comtypes==1.4.17；faster-whisper==1.2.1；ctranslate2==4.8.2；imageio-ffmpeg==0.6.0；语音权重来自 Systran/faster-whisper-small。运行依赖目录的 dist-info/METADATA 保存其余实际版本。Ollama 模型 qwen3-vl:2b 不随更新包重复下载。

官方来源：https://github.com/deepseek-ai/deepseek-harness 。本地 SDK 小改动：Windows 子进程加入 CREATE_NO_WINDOW，保留其许可证。语音依赖小改动：faster_whisper/audio.py 使用已安装的 FFmpeg 静态程序解码，避免本机应用控制阻止 PyAV 加载与 av19 参数不兼容；最长读取180秒。该改动保留在交付的依赖源码中。

构建：先安装原军师基础程序，运行开发包 prepare_release.py 准备文件，再用 Inno Setup 6 编译 update.iss。包是更新包，复用原启动器及嵌入 Python。运行 tests_core.py、check_legacy_features.py、test_real_models.py、test_av.py；真实模型测试需要用户在应用中设置密钥。测试脚本应保留在工作目录，不要发布包含真实聊天内容的测试数据和 Harness 会话日志。


## 本次最终补充

Harness 不是空工具框架：实际通过官方 Cordis `insert` 配置挂载唯一只读 MCP 工具 `read_observations`，从 DPAPI 快照读取应用选择的消息证据。禁用 PowerShell、bash、PTY、终端、标题生成与 SDK 自动多次重试；真实 nonce 测试确认 tool/call 和 tool/result。不要把应用控制 API 的实例令牌放入 Harness。官方 SDK 0.1.5rc1，与 GitHub 当前开发版本分别记录，不能混称同一个版本。

`POST /attach-media` 由用户明确选定当前会话消息和已完成文件任务，把文件哈希、转写时间段、视频抽样、覆盖范围和不确定项写入消息证据。保留 original_observation；用户更正与文件关联不覆盖原始 OCR。`speaker_id: self` 可确认自身消息。原图只在内存缓存，重启需重新读取。

自动填入目前因最新列表位置无法独立验证而主动停止；这项不是已实现可开放的验收结果。不能删掉保护来声称完成。其他模型、插件都不能越权打开自动发送，应用没有发送端点。

插件回滚：停用对应扩展，退出程序；备份插件目录，再复制回已审阅的旧版文件，重新执行 --verify 后启用。新代码摘要改变会失效。是文件版本恢复而不是恶意代码安全沙箱。模型并发目前固定保守串行，费用由调用估算控制，非账单硬封顶。

证据数据约保留七天、最多两万条观察；密钥与确认记忆加密，观察数据库不整体加密。不要分享 private-data-backup、dev-data、test-data 或用户 Harness 日志。

恢复：执行交付目录 恢复到1.3.0.ps1，将升级前程序文件复制回原目录，不递归删除用户目录；默认保留当前密钥和用户数据。加 -RestorePreferences 可恢复备份偏好。恢复后新版本额外依赖可继续存在，但原版不会加载它们。更新包需已有 Junshi 1.3 安装，不是从零安装器。
