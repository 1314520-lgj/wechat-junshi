# 军师 1.4 使用说明

安装前保留本目录的 backup-1.3.0 和 private-data-backup。后者属于私有备份，可能包含加密密钥和会话数据，请勿随开发包分享。更新包用于已经安装军师的电脑。

打开微信会话，军师读取当前可见消息；展开“核对军师实际读到的消息”查看原始读回、内容类型、不确定项和原图证据。多行消息可以查看整段截图。点击更正可改文字、类型、昵称和人物关联。更正属于应用记录，不修改微信聊天记录。截图缓存有容量限制，过期后需要重新读取。

头像和昵称都是身份线索，不是可靠的微信账号。没有足够证据时应用保留独立待确认线索，可能一位联系人出现多条线索。只有用户明确关联后才标记已确认。群成员列表仅覆盖实际观察到的内容，不能代表全部群成员名单。

默认使用本机 Ollama 的 qwen3-vl:2b 理解图片，DeepSeek 起草并复核回复。请确认 Ollama 已启动。兼容地址为 http://127.0.0.1:11434/v1。密钥在设置中输入，由 Windows DPAPI 绑定当前用户保存。云端模型会收到参与分析的聊天文字，视觉默认在本机运行。

设置中的“模型协作与扩展”可以增加 OpenAI 兼容模型、选择起草/复核/语境理解/候选评估职责、停用或提高优先级。同一职责优先使用列表中第一个已启用模型。不需要所有模型每次参与。单次分析有时间和逻辑调用次数限制；费用上限使用用户填入的单次费用估算，未知价格填写零，不能保证服务商账单中的实际金额。远程重试与 Harness 内部请求可能增加实际 HTTP 请求次数。

Harness 使用官方 Python SDK 0.1.5rc1 的独立进程，关闭终端工具。启动失败时返回基础接口。当前版本不向 Harness 开放应用管理、微信输入或发送工具。只把应用规定的任务作为可信指令，聊天内容是待分析的数据。SDK 为预发布版本，故障降级不会赋予模型更多权限。

视频封面只代表封面。需要理解语音或视频时，先从微信手动保存文件，再在“理解本地视频与语音文件”中导入；支持至多 20MB 文件，音频转写最多前 180 秒，视频抽取三处画面。它不是逐帧完整理解，未处理部分明确未知。字幕、转写和模型理解都可能出错，应核对原始证据。

自动填入开关默认关闭。开启后仍需通过当前会话、消息时效、前台窗口、用户活动与空输入框检查。已有文字或附件草稿时跳过。手动填入也不覆盖已有草稿。军师不自动发送，不代替用户作出付款、工作进度或交付承诺。切换会话后旧任务取消，旧建议标记过期；错误留在页面，可按提示针对性重试。

确认事实使用“记录我已确认的会话事实”。识别结果和模型推测不会自动升级为真实记忆。旧版自动生成的未确认记忆不再直接作为确认事实使用。

扩展默认停用，只启用自己审阅并信任的代码。清单声明 read_context 权限，启用前做静态检查、真实执行测试和 SHA256 指纹验证；代码改动后自动停用，重新验证才可启用。子进程提供故障隔离，并非操作系统安全沙箱。回滚扩展时恢复已知版本的文件，然后重新验证；不要把未知来源代码当作可信插件。

会话观察记录在本机 SQLite 保存，保留最近七天并限制 20000 条。它目前不是加密数据库；密钥与用户确认记忆使用 DPAPI。Harness 会话日志也可能包含参与云端分析的聊天上下文。开发包和公开测试报告不包含真实聊天原文、私有配置或密钥。


## 1.4.0 当前版本提示

自动填入开关默认关闭。由于当前微信没有可靠最新消息位置证据，开启后会显示跳过原因；请核对读取内容后使用“填入微信”。填入只操作空输入框，不发送；已有文字或附件会保留。测试中实际手动填入已成功。

语音、视频请先把文件保存到电脑，在应用导入，完成后点击“确认文件所属消息并用于回复”，明确选择对应微信消息。不要把其他文件关联到消息。转写和抽样画面仍可能错误，最长180秒、20MB；视频抽样不是完整视频理解。

最近消息可查看裁剪证据、更正文字、类型和人物；无法看懂的媒体保留未知。群成员列表仅表示已观察人物线索，不是全群名单。同名会话需特别人工核对。

请阅读 真实测试报告.md 和 已知限制.md。backup-1.3.0 是原程序可恢复备份；private-data-backup 含个人数据，不要发给别人；开发包已经排除这些数据。
