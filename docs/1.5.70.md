# 军师 1.5.70

在已有 1.5.69 自适应排版基础上，修正日常使用中可能出现的旧建议和事实归属问题。

## 本轮变化

- 人物归属参与建议缓存。不同发言者不能因同昵称、同文字而复用另一人的核验结果；归属关系相同且证据、设置不变时仍可复用，避免随机观察编号导致重复调用。
- 红包、转账和公众号/链接/应用入口的操作确认绑定当前卡片。旧对象的领取、收款或阅读记录不证明新对象已完成；只展示卡片状态不证明本人操作。
- 条件和将来表达不冒充完成事实。普通词中的“要、会、等”不能绕过核验；已有事实和承诺限制继续生效。
- 修改粘贴原文、回复对象或口吻后，待采用的旧建议立即失效，保留自己编辑的文字。主动查看有效新建议后，旧建议提示消失。
- 手动填入或复制失败时提示对应操作和恢复方式，避免把填入失败引向额外模型生成；复制重试使用当前编辑文字。

## 验证与使用

本轮 553 项有效离线检查、25 项新增界面交互检查、251 项自适应检查、15 项已有交互检查、76 项视觉与排版检查通过。
原有 3 个已失去集成目标的历史检查继续标为跳过，没有计入有效检查。新增界面测试另复现旧版 4 个失败条件。
使用虚构会话、模拟服务与本地浏览器，没有真实模型费用或微信操作；这些结果不能代表长期真实聊天准确率。

新增公开测试可按根目录 README 运行。报告：[离线回归](qa/final-1.5.70-regression.json)、[新增交互](qa/final-1.5.70-actions.json)、[自适应](qa/responsive-1.5.70.json)、[原有交互](qa/final-ui-1.5.70.json)、[视觉与排版](qa/visual-ux-1.5.70.json)。

打开桌面军师即可使用，设置和密钥不需要重新填写。陌生表情、反话和模糊截图仍可能识别错误；证据不足时保持未知，可在消息核对中更正。
